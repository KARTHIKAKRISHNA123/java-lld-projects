# Java LLD Practice Projects

This repository contains a curated collection of **Java Low-Level Design (LLD) projects and games**.  
The goal is straightforward: sharpen core Java skills, master loops and control flow, and build solid design intuition through hands-on systems.

This repo is focused on:
- core Java
- loop-heavy logic
- object-oriented design
- console and game-based projects
- real-world mini system implementations
